# Invest Detroit Project 2

Team repository for the Business+Tech AI Sprint (U-M Ross, Fall 2026), built for **Invest Detroit**, Michigan's largest community development lender (CDFI).

## The idea

Invest Detroit's credit staff take about **17 days** to turn a borrower's documents into an Investment Summary: they re-type numbers into a template, then analyze them by hand. Our assistant does the first draft in minutes:

1. **Reads** the borrower's scanned PDFs (financial statements, tax returns, projections, rent rolls, appraisals, budgets).
2. **Calculates** debt service coverage (DSCR), every ratio, break-even sales or vacancy, loan to value and cost. All math is plain code, never AI guesses.
3. **Checks** the loan against Invest Detroit's Credit Guidelines (rev. 4/2026) and flags statements that do not add up.
4. **Benchmarks** the business against its industry using its NAICS code and IRS tax-return averages.
5. **Drafts** the Investment Summary in Invest Detroit's own layout, plus a draft term sheet. An underwriter edits any input, sees the numbers update, and exports Word.

The tool drafts; people decide. It never makes the lending decision.

**Who uses it:** Invest Detroit loan officers, underwriters and the approval committee. Borrowers do not use it.

## What is in this repository

| Where | What |
| --- | --- |
| `src/`, `public/`, `index.html` | The website (React + Vite). It shows **pre-computed examples for twelve fictional companies**: eight small businesses (including a software start-up and a big tech firm) and four real estate projects. |
| `public/demo/` | The example data and a Word draft for each fictional company. Generated by the Python tool. |
| `underwriter-tool/` | The full Python tool: reading PDFs with Claude, the calculation engine, guideline checks, NAICS benchmarks, memo writer, Word export, its own review screen, tests, and the test harness with 580+ fictional borrowers. See `underwriter-tool/README.md`. |
| `START-HERE.md`, `PROMPTS.md` | How the team works with Claude, and ready-made prompts. |

The website can only host static pages (no server), so it cannot run the Python engine live. The examples were produced ahead of time by the real engine. To refresh them after changing the engine:

```
cd underwriter-tool
pip install -r requirements.txt
python scripts/export_demo.py
```

## How well does it work?

- Compared with two real Invest Detroit Investment Summaries: **387 figures checked, none unexplained** (the few differences are spreadsheet errors in the originals, documented in `underwriter-tool/docs/sample-findings.md`).
- Tested on **580+ fictional borrowers** (restaurants, manufacturers, child care, start-ups, apartment buildings and more) against an independent answer key: **43,039 of 43,051 checks pass**. The only misses are the backup industry-code guess, which always asks the underwriter to confirm.
- Deliberately mistyped statement figures: **all caught**. Statements left in thousands, flipped signs and duplicate uploads: all caught.
- **Not yet tested:** Claude reading real scanned PDFs (needs an API key). Run `underwriter-tool/scripts/eval_live_extraction.py` first once one is available. Every extraction needs an underwriter's review.

The full round-by-round log is in `underwriter-tool/docs/test-loop-log.md`.
